# NowBank

Fictional banking app used as the target in the Flutter 3.50 Android Intent
hardening lab described in the [root README](../README.md).

## Running

Pinned to Flutter 3.47.9 via FVM (`.fvmrc`):

```bash
fvm flutter run
```

See the root README for the full attack/build scripts (`../scripts/`) and the
scenario-by-scenario walkthrough.
